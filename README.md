# What If FC ⚽👻

**A normal dashboard tells you what happened. What If FC shows what else could have happened – and proves why.**

What If FC streams synthetic football events through **Microsoft Fabric**, detects key moments with **KQL**, finds a better alternative to the pass that was played (the **Ghost Pass**), and uses **Microsoft Agent Framework** agents on **Microsoft Foundry** to explain it two ways: for the analyst and for the fan. Every claim on screen links back to its evidence.

> Entry for the Microsoft Premier League Hackathon (Inside the Game), October 2026. All clubs, players and match data are fictional and generated by this project.

## How it works

```text
Simulator ─► Fabric Eventstream ─► Eventhouse (KQL: live stats, key moments)
                     └──────────► Lakehouse ─► Data Factory pipeline ─► recap
Key moment ─► Tactical Twin (Ghost Pass scoring, Python)
           ─► Agent 1 Investigator ─► Agent 2 Broadcast Director ─► Validator
           ─► React app (Analyst / Fan, Evidence Ledger)   + replay store (Blob)
```

Full requirements, design and plan: [`docs/requirements.md`](docs/requirements.md).

## Quick start (local)

Requires Python 3.11 or newer.

```bash
git clone https://github.com/<your-username>/what-if-fc.git
cd what-if-fc
python -m venv .venv
# Windows: .venv\Scripts\activate     macOS/Linux: source .venv/bin/activate
pip install -e ".[dev]"

python -m simulator.reference_data   # writes data/reference/teams.json, players.json
python -m simulator.samples          # writes data/samples/*.json
ruff check . && pytest -q            # lint + tests
```

**Git hooks:** run `git config core.hooksPath .githooks` once after cloning.
A **pre-push** hook runs `ruff check .`, `pytest -q`, and (when `web/` files
changed) `npm --prefix web run lint` and `npm --prefix web test`, aborting
the push on failure.

Copy `.env.example` to `.env` when you reach the Azure steps; never commit `.env`.

## Building replay bundles

Replay bundles are self-contained JSON files stored in `data/replay/` (git-ignored). They let the React frontend work with Fabric paused.

```bash
# Build all bundles using template-only overlays (free, no Azure credentials needed)
python -m scripts.build_replay

# Build with agent-generated overlays (requires FOUNDRY_PROJECT_ENDPOINT + FOUNDRY_MODEL in .env)
python -m scripts.build_replay --agents

# Build and upload to Azure Blob Storage (requires REPLAY_STORAGE_ACCOUNT_URL in .env)
python -m scripts.build_replay --upload
```

This produces one JSON bundle per replay ID:
- `match_s7_T01_T02.json` — full 90-minute seeded match (seed=7)
- `scenario_<id>.json` — one file per hand-designed demo scenario

## Running the replay API

```bash
uvicorn api.main:app --reload
```

Endpoints:
- `GET /health` — liveness probe; returns `{status, mode, store}`
- `GET /api/replays` — catalog: `[{replay_id, kind, title, overlays}]`
- `GET /api/replays/{replay_id}` — full bundle (404 if unknown)
- `GET /api/replays/{replay_id}/overlays?since_clock_s=N` — overlays after clock position N (for AT-11 live-update shape)

The API uses **Azure Blob Storage** when `REPLAY_STORAGE_ACCOUNT_URL` is set; otherwise it reads from `data/replay/` locally.

## Honest labels

Tactical Twin values are heuristic **tactical option scores** (version `twin-v1`), not probabilities, expected goals or expected assists. Possession is an event-based proxy.
